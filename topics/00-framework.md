## 범용 20분 PT 구조 템플릿

어떤 주제가 나와도 아래 구조를 기본 뼈대로 활용할 수 있다.

| 파트 | 시간 | 역할 | 구성 요소 |
|------|------|------|-----------|
| **도입** | 2분 | 문제 인식 공유 | 주제 배경 1문장 → 왜 지금 중요한지 → 발표 흐름 예고 |
| **현황 분석** | 5분 | 근거 제시 | 서울대 현황 데이터 → 국내외 비교 사례 2~3개 → 현행 시스템 구조 |
| **문제 진단** | 4분 | 이슈 구조화 | 핵심 문제 3가지 도출 → 원인 분석(사람·프로세스·기술) → 방치 시 리스크 |
| **해결 방안** | 7분 | 실행력 어필 | 단기(6개월)·중기(1~2년)·장기(3년+) 구분 → 각 방안의 기대효과 → 정보화본부 역할 명시 |
| **마무리** | 2분 | 인상 남기기 | 핵심 메시지 1문장 재강조 → 정보화본부 미션 연결 → 실행 의지 표명 |

## 파트 전환 멘트 5개

자연스러운 흐름을 위해 각 파트 전환 시 활용할 수 있는 멘트다.

1. **도입 → 현황 분석**
   "이 문제의 실체를 좀 더 구체적으로 살펴보겠습니다. 현재 서울대와 주요 대학들의 상황을 비교해 보면—"

2. **현황 분석 → 문제 진단**
   "현황을 정리하면 세 가지 지점에서 구조적인 문제가 드러납니다."

3. **문제 진단 → 해결 방안**
   "그렇다면 이 문제를 어떻게 풀 수 있을까요. 정보화본부의 역할을 중심으로 실행 가능한 방안을 말씀드리겠습니다."

4. **해결 방안 → 마무리**
   "지금까지 제안한 방안을 한 문장으로 정리하면 이렇습니다—"

5. **마무리 시 미션 연결**
   "이 과제는 정보화본부의 [해당 미션명] 미션과 직접적으로 연결됩니다. 실무를 맡게 된다면 이 방향으로 기여하고 싶습니다."
