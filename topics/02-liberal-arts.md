# 2. 학부대학 출범과 기초교양 강화 전략

**한 줄 요약:** 학부대학 시스템화가 교양교육 혁신의 열쇠

**배경** (3줄 이내)
- 서울대는 자유전공학부를 넘어 학부대학 체제를 검토하며, 기초교양 교육의 질적 강화를 추진하고 있다.
- 1학년 공통 교육과정 운영은 수강신청, 분반 배정, 성적관리 등 시스템 전반에 영향을 준다.
- 학생 역량 기반 교육과정 설계를 위해 학습 데이터 분석 인프라가 필수적이다.

**20분 PT 구조**

| 파트 | 시간 | 핵심 내용 (키워드 중심) |
|------|------|------------------------|
| 도입 | 2분 | 대학교육 패러다임 전환, 학부대학 개념과 필요성 |
| 현황 분석 | 5분 | 국내외 학부대학 운영 사례(연세·하버드), 서울대 기초교육원 현황, 수강신청 시스템 부하 실태 |
| 문제 진단 | 4분 | 대규모 공통교과 분반 배정의 비효율, 학습성과 추적 시스템 부재, LMS와 학사시스템 간 데이터 단절 |
| 해결 방안 | 7분 | AI 기반 분반 최적 배정 알고리즘, LMS-학사시스템 통합 API, 학습 대시보드 구축, 역량 포트폴리오 DB 설계 |
| 마무리 | 2분 | 교양교육 혁신은 데이터와 시스템이 뒷받침할 때 실효성을 갖는다는 점 |

**핵심 논거 3가지**
1. 학부대학 운영은 전체 1학년(약 3,000명) 대상이므로, 수강신청 피크 트래픽 관리와 분반 배정 자동화가 핵심 기술 과제다.
2. 학습성과 데이터를 축적·분석할 수 있어야 교양 교육과정의 실질적 개선이 가능하다.
3. LMS(eTL)와 학사시스템(SAP) 간 실시간 연동이 안 되면 이중 행정이 발생하고, 데이터 신뢰도가 떨어진다.

**서울대 정보화본부 미션 연결**
- **데이터기반행정**: 학습성과 데이터 수집·분석, 교육과정 효과 측정
- **정보서비스만족도**: 수강신청 안정성, LMS 사용자 경험 개선
- **지능형캠퍼스**: AI 기반 분반 배정, 개인화 학습 추천

**예상 꼬리 질문 2가지**
- Q1: 학습 데이터 수집 시 학생 개인정보 보호와의 균형은 어떻게 잡을 것인가?
- Q2: 수강신청 시스템의 피크 부하를 기술적으로 어떻게 해결할 수 있는가?
